## 第一条 定义与托管性质

1.1 「托管服务」：乙方将其作品的日常运营（分发排期、投放调优、奖励发放、数据监测、动态运营动作）委托平台运营 Agent 自动化执行的服务。

1.2 「运营 Agent」：平台部署的自动化运营程序，在本协议授权边界内代乙方执行运营动作。

1.3 托管为委托代理关系：Agent 在授权范围内的操作视为乙方的意思表示，其法律后果由乙方承受，但因平台系统故障或越权操作导致的后果除外（见第六条）。

1.4 托管不改变作品权利归属（仍按 AV-LGL-003 执行），也不免除乙方作为内容责任主体的义务。

## 第二条 托管权限边界

2.1 授权采用「白名单 + 分级确认」模式，乙方在托管配置单中逐项勾选授权。未列入白名单的动作，Agent 一律不得执行。

2.2 动作分级：

| 级别 | 动作类型 | 执行方式 |
| --- | --- | --- |
| A 级（自动执行） | 排期发布、素材轮换、频次调节、数据拉取 | Agent 自动执行，事后可查 |
| B 级（阈值内自动） | 预算内追投、奖励发放、渠道加减权重 | 阈值内自动，触线即停 |
| C 级（人工确认） | 大额动作、新渠道开通、奖励规则变更、内容实质修改 | 推送乙方确认后执行 |
| D 级（禁止托管） | 提现操作、协议签署、KYC 变更、账号安全设置 | 仅乙方本人操作 |

2.3 预算上限（三级熔断）：

1. 日预算限额：Agent 单日累计消耗不得超过乙方设定的日限额，触达即停止付费动作并通知乙方。
2. 单动作限额：单笔投放/奖励动作金额不超过乙方设定的单笔上限，默认不超过日限额的 20%。
3. 异常波动冻结：消耗速率、转化成本偏离基线超过设定阈值（默认 ±50%）时，自动冻结投放并告警。

2.4 大额动作人工确认：超过单笔上限或累计达到日限额 80% 后的付费动作，均属 C 级，须经乙方在确认通道明示同意后执行；乙方 24 小时未响应的，动作取消而非默认执行。

2.5 平台承诺 Agent 遵守各分发平台速率基线，模拟合理操作节奏，不采用可能触发第三方平台风控的自动化手段。因 Agent 违反本款导致乙方账号被第三方平台处罚的，责任由平台承担。

## 第三条 密钥与账号安全

3.1 乙方授权托管的第三方账号凭证与 API 密钥由平台加密托管，实行最小权限原则——仅授予完成白名单动作所必需的权限范围。

3.2 密钥使用全程留痕；乙方可随时在控制台查看密钥调用记录并一键吊销授权。

3.3 平台不得将乙方密钥用于本协议以外的任何用途，不得向第三方披露。

## 第四条 操作留痕与回滚

4.1 全量留痕：Agent 的每一次操作记录以下字段并不可篡改存储：操作时间、动作类型、决策依据（触发规则/数据信号）、执行结果、关联消耗金额。日志留存不少于 24 个月。

4.2 可查可导出：乙方可实时查看操作日志，并按月导出对账用副本。

4.3 回滚机制：

1. 可回滚动作（排期、权重、素材配置类）：乙方可在控制台一键回滚至任一历史配置版本。
2. 不可逆动作（已发放奖励、已消耗投放）：无法物理回滚，但乙方可发起争议核查；查实为 Agent 越权或系统故障所致的，按第六条赔付。

4.4 一键暂停：乙方可随时暂停全部托管动作，暂停指令在系统内 5 分钟内生效；暂停不影响已进入第三方平台执行队列的动作。

## 第五条 托管期数据与收益归属

5.1 数据归属：托管期间产生的运营数据（投放明细、玩家行为、转化漏斗）归乙方所有；平台可使用脱敏聚合后的数据优化 Agent 策略与形成行业基准，不指向乙方个体。

5.2 收益归属：托管作品产生的收益归乙方，按乙方身份对应的协议（AV-LGL-004 或 AV-LGL-005）结算路径与周期执行；平台按托管配置单收取托管服务费（固定费或收益百分比）。

5.3 托管费从结算收益中优先扣除；收益不足以覆盖托管消耗的，差额由乙方在对账后 15 日内补足。

5.4 托管终止后，运营数据完整副本向乙方开放导出 90 天，逾期归档；平台保留法定留存义务范围内的记录。

## 第六条 责任划分

6.1 平台责任：Agent 超越授权边界操作、熔断机制失效、密钥泄露（因平台过错）、系统故障导致的直接资金损失，由平台据实赔偿。

6.2 平台赔偿上限：除故意或重大过失外，平台在本协议项下的累计赔偿责任不超过乙方过去 12 个月已支付托管服务费的 2 倍。

6.3 乙方责任：授权范围设定不当、乙方自行修改配置导致的损失、内容本身违规导致的下架与处罚，由乙方承担。

6.4 免责：因第三方平台政策变更、API 中断、不可抗力导致托管动作失败或延迟的，双方均不担责，平台应及时通知并调整策略。

## 第七条 托管配置单必备要素

7.1 托管配置单是本协议的执行附件，每次开启托管前须完成，至少包含：

1. 托管作品清单与托管期限。
2. A/B/C 级动作白名单勾选结果。
3. 日预算限额、单动作限额、异常波动阈值三项熔断参数。
4. 确认通道与确认人（C 级动作的接收端与备用联系人）。
5. 托管服务费模式（固定费/收益百分比）与费率。
6. 授权的第三方账号与 API 权限范围清单。

7.2 配置单参数由乙方自行设定并可随时收紧；放宽参数（提高限额、扩大白名单）须经二次验证确认后生效。

## 第八条 协议期限与终止

8.1 本协议自签署起生效，与托管配置单同期有效；乙方可随时终止托管，平台在 24 小时内停止全部 Agent 动作并交还密钥授权。

8.2 平台可在乙方违反内容合规义务或欠付托管费超 30 日时暂停或终止托管。

8.3 托管作品因 AV-LGL-008 违规被下架的，对应托管动作自动暂停，已产生的托管费不予退还。

8.4 终止后的数据导出、未结收益、留痕保存义务按第四、五条执行。

## 附则

1. 修订机制：本协议及动作分级白名单由平台维护，修订提前 15 天通知托管中的乙方；扩大 Agent 自动权限范围的修订，须经乙方重新勾选确认方对其生效。

2. 语言版本：本协议以中文、英文双语发布，歧义时以英文版本为准，乙方所在司法区强制要求除外。

3. 生效方式：乙方在线签署并完成托管配置单勾选后生效；本模板自 2026-07-14 起启用。

4. 争议解决：参照 AV-LGL-001 第八条执行；托管操作争议以第四条操作日志为核查基础。

5. 联系方式：托管与法务事项请致函 legal@airvana.ai。
