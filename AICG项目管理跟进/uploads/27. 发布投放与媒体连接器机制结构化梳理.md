# 发布投放与媒体连接器机制结构化梳理

## 1. 核心定义

发布投放与媒体连接器机制，是把审核通过的 Agentic Playable 推向外部用户的分发层。

它负责生成发布链接、渠道链接、分享卡、归因参数、连接器状态，并把投放后的数据回收接入后续 Runtime 和数据反馈。

核心产物：

| 产物 | 说明 |
|---|---|
| `publish_url` | 主发布链接 |
| `channel_links` | 不同渠道的归因链接 |
| `share_card` | 分享素材 |
| `connector_status` | 媒体连接器状态 |
| `attribution_config` | 归因配置 |

## 2. 所处位置

| 上游 | 当前环节 | 下游 |
|---|---|---|
| `approved_playable_version` | 发布投放与媒体连接器 | Runtime Agent 动态运营 |

## 3. 业务目标

| 目标 | 说明 |
|---|---|
| 正式发布 | 把通过审核的版本变成可访问链接 |
| 渠道分发 | 支持 KOL、社群、广告、官网传播 |
| 数据归因 | 知道用户来自哪个 KOL、渠道、版本 |
| 媒体连接 | 支持 X、Telegram、Discord 等连接器 |
| 发布监控 | 检查链接健康和渠道状态 |

## 4. 输入数据

| 输入 | 用途 |
|---|---|
| `approved_playable_version` | 发布版本 |
| `share_card` | 外部分享素材 |
| `channel_plan` | 渠道计划 |
| `kol_context` | KOL 专属链接和分享 |
| `tracking_map` | 归因和事件 |
| `publish_policy` | 平台审核和渠道规则 |

## 5. 关键 Agent / 系统

| 模块 | 职责 |
|---|---|
| Publish Agent | 发起发布 |
| Connector Agent | 调用媒体连接器 |
| Link Service | 生成链接 |
| Attribution Service | 生成归因参数 |
| Share Card Service | 生成分享卡 |
| Channel Monitor | 监控渠道状态 |
| Publish Audit | 记录发布审计 |

## 6. 渠道类型

| 渠道 | 重点 |
|---|---|
| X / Twitter | 分享卡、标题、短链、转发 |
| Telegram | 入群、社群任务、KOL 私域 |
| Discord | 身份、社区任务、角色 |
| 广告渠道 | UTM、投放参数、落地页表现 |
| 官网 | 产品转化和品牌承接 |
| KOL 私域 | 专属链接、粉丝榜、分享裂变 |

## 7. 归因参数

| 参数 | 说明 |
|---|---|
| `campaign_id` | 活动 |
| `kol_id` | KOL |
| `playable_version_id` | 版本 |
| `template_id` | 模板 |
| `channel` | 渠道 |
| `connector_id` | 连接器 |
| `share_id` | 分享链路 |
| `utm_source` | 来源 |
| `utm_campaign` | 活动 |

## 8. 发布流程

| 步骤 | 说明 |
|---|---|
| 1 | 确认版本审核通过 |
| 2 | 锁定版本 |
| 3 | 生成主 `publish_url` |
| 4 | 生成渠道链接 |
| 5 | 注入归因参数 |
| 6 | 生成分享卡 |
| 7 | 调用媒体连接器 |
| 8 | 检查链接健康 |
| 9 | 开始监控数据 |
| 10 | 进入 Runtime Agent |

## 9. 约束边界

| 约束 | 说明 |
|---|---|
| 未审核版本不能发布 | 平台审核必须先通过 |
| 链接必须可归因 | 每个渠道有参数 |
| 发布后不原地修改 | 修改必须新版本 |
| CTA 链接必须校验 | 防止钓鱼和错误跳转 |
| 渠道规则要遵守 | 不同平台有不同限制 |

## 10. MVP 范围

| P0 能力 | 说明 |
|---|---|
| 主发布链接 | 可访问 |
| 渠道归因链接 | 至少支持手动复制 |
| 分享卡 | KOL 可转发 |
| 链接健康检查 | 404、跳转、CTA |
| 基础连接器 | 先接 1-2 个高价值渠道 |
| 发布日志 | 记录版本和渠道 |

## 11. P1 / P2 扩展

| 阶段 | 能力 |
|---|---|
| P1 | 多渠道连接器、自动发布、渠道看板 |
| P2 | 预算联动、自动投放建议、渠道质量评分 |

## 12. 验收标准

| 验收项 | 标准 |
|---|---|
| 可访问 | `publish_url` 正常 |
| 可归因 | 不同渠道数据可区分 |
| 可传播 | 分享卡正常显示 |
| 可监控 | 渠道状态和链接健康可看 |
| 可回收 | 数据能进入 Runtime 和 Analytics |

## 13. 最终结论

发布投放是 Agentic Playable 进入真实业务环境的入口。

它不是简单生成链接，而是把版本、渠道、连接器、分享卡、归因和数据回收打通。
